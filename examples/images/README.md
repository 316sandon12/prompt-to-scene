# Game image example

`healing-potion.png` is an original AI-generated example produced with the built-in imagegen tool
for this repository on 2026-10-13. No third-party reference images were supplied. It is included
under the repository's MIT license. Source: 1254 × 1254 RGBA PNG; the image workflow prepares
a 256 × 256 icon while retaining the original bytes and real transparency.

Use **Workbench → 图片与 UI → 试用示例图标**, or execute `image_example` through `game_workflow`.
The example ships with both portable apps and the Python package.

Generation prompt:

Primary request: a charming handcrafted healing potion from a cozy herbalist village, squat clear mint-green glass flask holding muted jade liquid, warm cork stopper, simple twine wrap, one tiny sage leaf charm; beautiful intentional silhouette readable at 64 pixels, clean painterly forms with restrained highlights, premium indie RPG inventory art. Composition: centered single object with a slight three-quarter view, complete silhouette with ample transparent margin on all sides, square canvas. Palette: muted deep teal, sage green, warm honey cork, tiny cream highlights. Constraints: real transparent alpha background, no cast shadow outside the object, no text, no letters, no label writing, no decorative frame, no border, no background scene, no checkerboard painted into the image, no watermark. One icon only.

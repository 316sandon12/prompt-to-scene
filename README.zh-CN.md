# Prompt-to-Scene

**用指令在 Blender 制作风格统一的道具，比较造型，修改部件，然后直接放进 Unity 或 UE。**

[English](README.md) · [下载](https://github.com/316sandon12/prompt-to-scene/releases/latest) · [新手安装](docs/QUICKSTART.zh-CN.md) · [v0.7 六项功能](docs/DEVELOPMENT.zh-CN.md) · [实际测试](docs/verification.md)

连接 **Codex / DeepSeek Harness → Blender → Unity / Unreal Editor**。自然语言由你现有的 AI 客户端理解，Blender 在本地运行；插件完成材质准备、原生导入、场景摆放和结果检查。下载程序自带 Python，不需要另买建模 API。

> v0.7 为实验版，支持不透明道具、三种交互模板和模块关卡。需已安装 Blender、引擎编辑器和可正常对话的 AI 客户端；工作台也能直接操作，无需调用模型。

![实际 Blender 模型与烘焙材质](docs/images/authoring-chair.png)

*内置椅子的实际 Blender 工作室渲染，包含可编辑部件和烘焙 PBR 材质。引擎中的灯光与显示效果会不同。*

## 三步开始

[**Windows x64**](https://github.com/316sandon12/prompt-to-scene/releases/latest/download/Prompt-to-Scene-windows-x64.zip) · [**Mac Apple Silicon**](https://github.com/316sandon12/prompt-to-scene/releases/latest/download/Prompt-to-Scene-macos-arm64.zip)

1. 完整解压并打开 **Prompt-to-Scene**。
2. 选择游戏项目，点击 **连接并准备项目**。程序自动检测 Blender、安装引擎桥接组件。
3. 点击 **安装 Codex 插件** 或 **安装 Harness 插件**，重启客户端，在新对话里开始使用。

保持引擎打开并退出 Play 模式。UE 首次安装桥接插件后重启一次。然后说：

> 用 Prompt-to-Scene，把这个项目设为温暖卡通风格。先给我三种椅子造型比较，选好以后再放进项目。

也可以打开 **创作工作台**，选择道具，点 **先比较三种造型**，选中后点 **选择并制作成品**。普通请求可直接制作，无需每次挑方案。首次只想验证连接，点 **生成示例木箱** 即可。

Mac 社区构建采用临时签名、未公证；Windows 构建未签名。系统首次打开提示与客户端安装问题见 [新手教程](docs/QUICKSTART.zh-CN.md)。

## v0.7：从模型到可测试的场景

| 新增功能 | 实际效果 |
| --- | --- |
| 玩法模板 | 制作带木纹 PBR 和独立活动网格的门、宝箱、拾取物，生成 Unity prefab 组件／UE 子 Blueprint；带距离判断、演示输入和项目事件入口。 |
| 保留开发设置 | 再次生成同一资产，保留材质引用、交互参数、根挂点和实例身份；缺少受保护槽位时提前阻止覆盖，可先做候选预检。 |
| 场景风格 | 温暖卡通、冷色科幻、月夜、中性四套灯光／天空／调色，固定机位比较，并可恢复原灯光。 |
| 模块关卡 | 房间、走廊、楼梯按接口连接；检查连通图、门洞尺寸和原生胶囊净空，失败时清理临时几何并保留旧关卡。 |
| 真实试玩检查 | 实际进入 Unity Play／UE PIE，测试交互与通道、记录前后截图、帧间隔和运行错误，完成后回到编辑模式。 |
| 项目素材复用 | 按名称、标签和尺寸搜索已有模型／prefab／兼容 Blueprint，原生缩略图预览，放置原资源引用，记录来源和许可证。 |

直接说：**“做一扇可交互木门，应用温暖卡通灯光，再进 Play 检查开关门”**。或在工作台打开 **玩法／关卡／素材库**，场景风格在 **视觉** 页。[完整按钮、提示词与边界说明](docs/DEVELOPMENT.zh-CN.md)。

UE 普通用户不需要 C++ 编译器；内置 Blueprint 模板以 5.7.2 保存，使用交互资产时需保留插件内容。关卡目前是 blockout 与采样净空检查，不包含 NavMesh；素材检索是关键词检索；帧时间只代表当前编辑器和机器。

## v0.6：六项新增工作流

| 功能 | 现在可以做什么 |
| --- | --- |
| 统一创作台 | 本地窗口与可选聊天内界面共用任务、选择、真实预览、取消和恢复；不依赖宿主支持内嵌 UI。 |
| 整套场景布置 | 三套搭配自动制作并布置，支持任意水平角度、贴地、朝向参照物、保存布局、复制复用和撤销。 |
| 美术检查与修复 | 保存图片/文字参考，读取原生问题，记录同一机位前后图；最多两次具体修复，每次完成后自动重新对照。 |
| 外部模型部件编辑 | 给已有网格分组、独立锁定、局部替换；保留未修改几何，复用未变材质的烘焙和引擎网格。 |
| 按用途优化 | 引擎实测面数、顶点、材质、纹理、LOD；移动端/场景/近景预设，不虚构 FPS。 |
| 可选 AI 生成服务 | Meshy 文字/图片生成，或自托管接口；1–3 个候选接入整理、预览与原生导入，付费服务需明确选择。 |

例如：**“做一个整体旋转 35 度的阅读角并摆好”**、**“只改这个导入模型的金属边”**、**“对照保存的美术参考检查，并修复具体问题”**。[六项完整用法](docs/WORKBENCH.zh-CN.md) · [可选服务接口](docs/PROVIDERS.md)。

## v0.5：从素材到游戏资产

| 优化 | 实际效果 |
| --- | --- |
| 接入现有模型 | 本地 GLB、glTF、FBX、Blender 文件直接进入工作流；也能搜索、预览和导入 Poly Haven 的 CC0 模型。其他 AI 工具生成的文件同样可以使用。 |
| 自动整理游戏资产 | 设置面数、贴图与尺寸；保留原始模型，检查减面误差，烘焙常见不透明 PBR 和原模型法线，生成 Unity LODGroup／UE 原生 LOD 及碰撞。超出误差限制时保留几何或停止导入。 |
| 造型与效果更好比较 | 阅读角、乡村集市、工匠工作间三套搭配；九种道具各有三种结构造型；源模型使用一致工作室视角，引擎内可记录同一相机的修改前后图片；直接载入选中对象编辑。 |

例如：**“把下载目录里的 vase.glb 整理到 8,000 面，高 1.5 米，生成 LOD 并放进当前 Unity 项目。”** 或 **“找一个 Poly Haven 陶瓷花瓶，先给我看整理前后的效果。”**

文件导入不会调用付费生成服务；v0.6 可单独选择生成服务，再让结果进入同一套可检查、可修改的资产流程。[按钮与提示词教程](docs/AUTHORING.zh-CN.md#v05-素材接入自动整理与效果对比)。

## 六项基础创作功能

| 功能 | 开发者可以怎样用 |
| --- | --- |
| 项目美术风格 | 保存 Cozy、Heritage、Workshop 风格、配色、旧化和质量档；新道具继承同一套设置，可参考已有配方或绑定现有引擎材质。 |
| 有结构的道具库 | 木箱、桌子、椅子、路牌、凳子、长凳、木桶、柜子、置物架，共九种配方；带轮廓变化、倒角、支撑和连接件。 |
| 自动材质准备 | 内置木材、金属、漆面、石材自动生成 UV 并烘焙底色、粗糙度、金属度、法线；Unity 自动打包金属/光滑度贴图，UE 连接对应材质输入。 |
| 部件编辑与锁定 | “只加高靠背”“座面改成漆面”“锁住腿的形状”；形状锁和材质锁独立，整体修改时保留锁定部分。 |
| 根据场景摆放 | 读取真实对象边界，以选中的桌子/墙/柜子为参照，围绕、排成一行、放到下面或旁边；检查重叠、按需缩小、复制实例并支持撤销。 |
| 比较后再导入 | 两到三个真实 3D 草稿，工作室/正面/背面预览；候选不进入引擎，选好才烘焙并发布成品。 |

完整提示词、按钮操作与各功能边界见 [创作指南](docs/AUTHORING.zh-CN.md)。这六项功能同时接入两个 AI 客户端和本地工作台。

## 继续用对话修改

- “做一套同风格的桌子、椅子和柜子。”
- “只把这款椅子的靠背加高 15%，座面和腿保持原样。”
- “锁定靠背的形状，之后只改材质。”
- “围绕我在引擎里选中的桌子，摆四把椅子；完成后看真实引擎预览。”
- “把凳子放到桌子下面，空间不够时等比缩小。”
- “只把选中的这一把椅子染成绿色。”
- “撤销刚才的摆放”，或“恢复这款模型的上一版”。

部件编辑更新共享资产；单个实例的位置、旋转、缩放与染色直接在引擎执行。模型重建保留资产身份、已有实例的变换和本工具的染色覆盖。Unity 自定义脚本适合放在 prefab 根对象；UE 保留 Actor 名称和标签。场景/关卡由你正常保存。

## 范围与验证

当前支持静态网格、不透明 PBR、Unity Built-in/URP 和 UE 原生 Static Mesh。自定义模型可由 AI 编写 Blender Python，或接入其他工具生成的 GLB/glTF、FBX、Blender 文件。程序会保留配方、原始模型、源文件、来源说明、成功版本和检查报告。

内置配方和常见不透明 Principled PBR 可烘焙；混合着色器、透明、发光、骨骼动画、HDRP 和任意 Blueprint 图生成不在范围内，v0.7 提供三种固定玩法模板。图片转模型通过可选外部服务完成，插件不捆绑推理模型。减面误差使用双向表面采样，不是严格的最大误差保证；贴图和轮廓仍需查看实际预览。碰撞是近似形状；UE 分解没有生成凸包时使用原生 26-DOP 凸包并在报告中说明。配方候选是确定的结构变化，服务候选由外部模型生成。布局支持水平旋转，使用保守的有方向边界，不是精确凹形碰撞。报告不给审美打分。

已用真实 Blender 4.2、Unity 2022.3（Built-in/URP）与 UE 5.7.2 验证。Windows 打包检查与 Windows 引擎实测是两回事，具体通过项目见 [验证矩阵](docs/verification.md)。

贡献者运行 `uv sync --locked`，然后 `uv run prompt-to-scene-app`。[手动配置](docs/manual-setup.md) · [架构和工具](docs/architecture.md) · [资产约定](docs/asset-contract.md) · MIT 协议。
